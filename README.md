# 氣脈陪練

角落裡的靜默桌寵番茄鐘。分頁開著就照牆鐘走，切走不會暫停。劉看山在待機、計時、到點之間換姿勢。鼓勵框平常收著，到點或雙擊看山才展開一句，大約三秒半後收回。頁面不會向攝影機或麥克風要權限。

## 本地執行

```bash
npm install
npm test
npm run dev
```

開發伺服器在 port `4719`。

## 怎麼試

1. 重新整理，看右下角的看山從角落外爬上來，待機時會輕輕浮動，並在站立與眨眼之間慢切。
2. 選 **10 秒**，按開始。切到別的分頁再回來，剩餘時間照牆鐘減少，不會把離開的那段補回去。
3. 到點時會同時出現三件事：探出身子、揮手、亮燈的提醒泡泡；系統通知（若已允許）；分頁標題在「時間到」和原標題之間閃。
4. 雙擊看山，不必等計時結束，也會走同一套提醒。
5. 按 **EN** 再雙擊，英文提醒會用 `speechSynthesis` 唸出來。中文維持安靜。通知在按下開始或雙擊時才會詢問。
