# 氣脈陪練

角落裡的靜默桌寵番茄鐘。計時卡片預設收起，展開後卡片裡會出現一句草書或手寫體的鼓勵。劉看山會在待機、晃悠、瞌睡、運球、用電腦和打招呼之間換動畫。頁面不會向攝影機或麥克風要權限。

## 本地執行

```bash
npm install
npm test
npm run dev
```

開發伺服器在 port `4719`。

## 怎麼試

1. 重新整理。計時卡片預設收起。右下角的看山從角落外爬上來，待機時在站立、晃悠、瞌睡、運球之間輪換。
2. 按 **展開**。卡片裡會出現一句中文草書鼓勵，每次展開都會換一句。按 **EN** 會換成英文手寫體。
3. 選 **10 秒**，按開始。看山改成用電腦的動畫。切到別的分頁再回來，剩餘時間照牆鐘減少。
4. 到點時卡片會展開，英文狀態是 **Time's up**，看山改成打招呼。同時有系統通知（若已允許），分頁標題也會閃。
5. 雙擊看山會再展開卡片、換一句鼓勵，並短暫揮手，不會把計時標成時間到。英文會用 `speechSynthesis` 唸出來，中文維持安靜。
